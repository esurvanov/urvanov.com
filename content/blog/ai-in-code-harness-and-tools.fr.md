Codex ou Claude Code : pour l'accès au projet et les actions, ils sont presque identiques, et ils diffèrent par la famille de modèles (GPT pour Codex, Claude pour Claude Code) et par l'abonnement. Prenez donc celui dont votre équipe a déjà le modèle et l'abonnement. Cursor convient si vous travaillez dans un éditeur et voulez des modèles de plusieurs fournisseurs, Hermes Agent si vous avez besoin de n'importe quel modèle, y compris local. Ci-dessous : une carte, un tableau et un choix selon la tâche.

    <q t="Claude Code ou Codex">Ils se ressemblent pour l'accès au projet et les actions et diffèrent par le modèle (Claude et GPT) et par certaines fonctions qui changent d'une version à l'autre. Le choix dépend du modèle et de l'abonnement que l'équipe a déjà.</q>
    <q t="Cursor ou Claude Code">Cursor travaille dans un éditeur avec un projet ouvert et permet de choisir entre des modèles de différents fournisseurs. Claude Code mène une tâche de bout en bout dans le terminal, mais uniquement avec des modèles Claude.</q>
    <q t="Hermes Agent ou Claude Code">Hermes Agent est un harness open source : il connecte n'importe quel modèle, y compris local, et l'on paie au token. Claude Code est lié à la famille Claude et à un abonnement. Choisissez Hermes pour des modèles de plusieurs fournisseurs ou votre propre modèle.</q>
    <q t="Alternatives à Claude Code">Parmi celles traitées ici : Codex (même conception, modèles GPT), Cursor (un éditeur, modèles de plusieurs fournisseurs) et Hermes Agent. <a href="https://opencode.ai" target="_blank" rel="noopener">OpenCode</a>, <a href="https://aider.chat" target="_blank" rel="noopener">Aider</a>, <a href="https://cline.bot" target="_blank" rel="noopener">Cline</a> and <a href="https://goose-docs.ai" target="_blank" rel="noopener">Goose</a> sont conçus de façon similaire.</q>

    <ex>Une tâche pose deux exigences à un harness : a-t-il besoin du projet et quelle famille de modèles convient. Les agents des éditeurs fonctionnent avec une seule famille, Cursor et le chat offrent le choix entre Claude et GPT, et les harness open source acceptent n'importe quel modèle, y compris local.</ex>

Seule la composition diffère. La colonne « Via API » prend Hermes Agent en exemple ; il existe de nombreux harness open source, comme OpenCode, Aider, Cline et Goose, et ils sont conçus de la même façon.</b-why>

  <b-sublabel top="22">Chat et agent</b-sublabel>
  <b-qa>
    <q t="En quoi Claude Code diffère de Claude dans le chat">La famille de modèles est la même ; le harness diffère. Le chat répond dans une conversation et ne voit pas votre projet. Claude Code lit le code, modifie des fichiers et exécute des commandes dans le projet : dans le terminal, un éditeur, l'application de bureau ou un navigateur. <a href="https://code.claude.com/docs/en/overview" target="_blank" rel="noopener">Documentation</a></q>
    <q t="En quoi Codex diffère de ChatGPT">La même règle s'applique : les modèles GPT sont communs, l'environnement diffère. ChatGPT tient une conversation sans accès au projet ; Codex travaille avec le code et exécute des commandes.</q>
  </b-qa>
  <b-finding>
    <ex>Les quatre types diffèrent par deux propriétés : l'endroit où le code s'exécute et le mode d'accès au modèle. L'open source et l'entreprise tournent sur votre ordinateur et ne diffèrent que par l'accès au modèle, d'où vient la différence de coût.</ex>
    <gen>Les types locaux conviennent au travail avec des fichiers et des secrets sur votre ordinateur, le cloud aux tâches longues et parallèles, le chat aux tâches sans accès au projet. Les contraintes réduisent le choix : un abonnement entreprise n'est pas disponible dans toutes les juridictions<b-proof href="https://www.anthropic.com/supported-countries" quote="Anthropic: “To the extent permitted by law, Anthropic reserves the right to not provide its products or services to entities whose majority direct or indirect ownership is attributable to nations other than those listed in our Supported Regions Policy” — anthropic.com/supported-countries"/>.</gen>
    <do>Décidez si la tâche a besoin de fichiers sur votre ordinateur, si l'agent doit travailler sans vous, et quel modèle vous pouvez utiliser. Le premier cas oriente vers un type local, le deuxième vers le cloud, aucun des deux vers le chat.</do>

<b-chapter id="faq" icon="chat" title="Questions fréquentes">
  <b-faq-cards>
    <q t="Codex ou Claude Code : lequel choisir ?">Pour l'accès au projet et les actions, ils sont presque identiques ; ils diffèrent par le modèle, GPT pour Codex et Claude pour Claude Code. Prenez celui dont votre équipe a déjà le modèle et l'abonnement.</q>
    <q t="Cursor ou Claude Code ?">Cursor travaille dans un éditeur et offre des modèles de différents fournisseurs. Claude Code mène une tâche du début au résultat dans le terminal avec des modèles Claude.</q>
    <q t="Quelles sont les alternatives à Claude Code ?">Codex, conçu de la même façon avec des modèles GPT, Cursor avec son éditeur et Hermes Agent avec n'importe quel modèle. OpenCode, Aider, Cline et Goose fonctionnent de façon similaire.</q>
    <q t="Pourquoi les comparatifs de fonctions vieillissent-ils si vite ?">De nouvelles versions de Claude Code et de Codex sortent chaque semaine. Trois choses restent stables : la famille de modèles, la conception du harness et les façons de travailler avec l'agent.</q>
