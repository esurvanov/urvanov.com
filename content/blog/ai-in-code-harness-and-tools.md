  <b-why>Выбор начинается с задачи. Два круга — семейства моделей, Claude и GPT: положение продукта на карте показывает, с какими моделями он работает. Claude Code и Codex привязаны каждый к своему семейству, Cursor и чат находятся на пересечении, Hermes Agent целиком охватывает Cursor и чат, частично пересекается с Claude Code и Codex и выходит за оба круга: он подключает любые модели, в том числе локальные<b-proof href="https://hermes-agent.nousresearch.com/docs/integrations/providers" quote="Hermes Agent: локальные модели через Ollama, llama.cpp, vLLM или LM Studio — «Ollama runs open-weight models locally with one command.   <b-sublabel top="22">Частые вопросы</b-sublabel>
  <b-qa>
    <q t="Claude Code или Codex">По доступу к проекту и действиям они совпадают, различаются моделью (Claude и GPT) и отдельными функциями, которые меняются от релиза к релизу. Выбор определяют модель и тариф, которые уже доступны команде.</q>
    <q t="Cursor или Claude Code">Cursor работает внутри редактора с открытым проектом и даёт выбор между моделями разных вендоров. Claude Code ведёт задачу от начала до результата в терминале, но только на моделях Claude.</q>
    <q t="Hermes Agent или Claude Code">Hermes Agent — опенсорс-харнесс: подключает любые модели, в том числе локальные, оплата за токены. Claude Code привязан к семейству Claude и подписке. Hermes — если нужны модели разных вендоров или своя модель.</q>
    <q t="Аналоги Claude Code">Из разобранных здесь: Codex (то же устройство, модели GPT), Cursor (редактор, модели разных вендоров) и Hermes Agent. Похожим образом устроены <a href="https://opencode.ai" target="_blank" rel="noopener">OpenCode</a>, <a href="https://aider.chat" target="_blank" rel="noopener">Aider</a>, <a href="https://cline.bot" target="_blank" rel="noopener">Cline</a> и <a href="https://goose-docs.ai" target="_blank" rel="noopener">Goose</a>.</q>
  </b-qa>
  <b-finding>
    <ex>Задача задаёт харнессу два требования: нужен ли доступ к проекту и какое семейство моделей подходит. Вендорские агенты работают с одним семейством, Cursor и чат дают выбор между Claude и GPT, опенсорс-харнессы — любые модели, включая локальные.</ex>
    <gen>Сначала по задаче выбирают группу, затем продукт внутри группы. Claude Code и Codex различаются моделью и отдельными функциями харнесса, которые меняются от релиза к релизу, но концептуально устроены одинаково. Поэтому решающим оказывается то, какая модель и какой тариф уже доступны команде.</gen>
    <do>Сформулируйте задачу одной строкой и определите три условия: нужен ли доступ к проекту, требуется ли участие человека на каждом шаге и нужна ли модель другого вендора или локальная модель. По этим условиям выберите группу.</do>

  <b-sublabel top="22">Чат и агент</b-sublabel>
  <b-qa>
    <q t="Чем Claude Code отличается от Claude в чате">Семейство моделей одно, различается харнесс. Чат отвечает в диалоге и не видит ваш проект. Claude Code читает код, правит файлы и запускает команды в проекте: в терминале, редакторе, приложении или браузере. <a href="https://code.claude.com/docs/en/overview" target="_blank" rel="noopener">Документация</a></q>
    <q t="Чем Codex отличается от ChatGPT">То же правило: модели GPT общие, среда разная. ChatGPT ведёт диалог без доступа к проекту, Codex работает с кодом и запускает команды.</q>
  </b-qa>
  <b-finding>
    <ex>Четыре типа различаются двумя свойствами: где выполняется код и как устроен доступ к модели. Опенсорс и энтерпрайз работают на вашем компьютере и различаются только доступом к модели, отсюда разница в стоимости.</ex>
    <gen>Локальные типы нужны для работы с файлами и секретами на вашем компьютере, облако — для долгих и параллельных задач, чат — для задач без доступа к проекту. Выбор сужают ограничения: энтерпрайз-план доступен не во всех юрисдикциях<b-proof href="https://www.anthropic.com/supported-countries" quote="Anthropic: «To the extent permitted by law, Anthropic reserves the right to not provide its products or services to entities whose majority direct or indirect ownership is attributable to nations other than those listed in our Supported Regions Policy» — anthropic.com/supported-countries"/>.</gen>
    <do>Определите, нужны ли задаче файлы на вашем компьютере, должен ли агент работать без вас и какая модель вам доступна. Первое ведёт к локальному типу, второе — к облаку, отсутствие обоих — к чату.</do>
