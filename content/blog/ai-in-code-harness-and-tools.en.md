  <b-qa>
    <q t="Claude Code or Codex">They match in project access and actions and differ in the model (Claude and GPT) and in individual features that change from release to release. The choice is set by the model and plan the team already has.</q>
    <q t="Cursor or Claude Code">Cursor works inside an editor with an open project and lets you choose between models from different vendors. Claude Code takes a task from start to finish in the terminal, but only on Claude models.</q>
    <q t="Hermes Agent or Claude Code">Hermes Agent is an open-source harness: it connects any model, including local ones, and you pay per token. Claude Code is tied to the Claude family and a subscription. Choose Hermes for models from several vendors or your own model.</q>
    <q t="Claude Code alternatives">Of those covered here: Codex (the same design, GPT models), Cursor (an editor, models from several vendors) and Hermes Agent. <a href="https://opencode.ai" target="_blank" rel="noopener">OpenCode</a>, <a href="https://aider.chat" target="_blank" rel="noopener">Aider</a>, <a href="https://cline.bot" target="_blank" rel="noopener">Cline</a> and <a href="https://goose-docs.ai" target="_blank" rel="noopener">Goose</a> are built in a similar way.</q>

  <b-finding>
    <ex>A task sets two requirements for a harness: whether it needs the project and which model family fits. Vendor agents work with one family, Cursor and chat offer a choice between Claude and GPT, and open-source harnesses take any model, including local ones.</ex>
    <gen>First pick the group by the task, then the product within the group. Claude Code and Codex differ in the model and in individual harness features that change from release to release, yet conceptually they are built the same way. So what decides is the model and plan the team already has.</gen>
    <do>Describe the task in one line and settle three conditions: does it need the project, does it need a human at every step, and does it need another vendor’s model or a local model. Pick the group by those conditions.</do>

<b-chapter id="harness" icon="layers" title="What a harness is">
  <b-why>A model answers with text. The harness is everything around it: skills, tools, environment, the human in the loop. Every AI product has one, from a terminal agent to a browser chat<b-proof href="https://claude.com/blog/a-harness-for-every-task-dynamic-workflows-in-claude-code" quote="Anthropic calls Claude Code a harness: the post “A harness for every task” — claude.com/blog/a-harness-for-every-task-dynamic-workflows-in-claude-code"/>. What differs is the composition. The "Via API" column uses Hermes Agent as an example; there are many open-source harnesses, such as OpenCode, Aider, Cline and Goose, and they are built the same way.</b-why>

  <b-sublabel top="22">Chat and agent</b-sublabel>
  <b-qa>
    <q t="How Claude Code differs from Claude in chat">The model family is the same; the harness differs. Chat answers in a conversation and does not see your project. Claude Code reads code, edits files and runs commands in the project: in the terminal, an editor, the desktop app or a browser. <a href="https://code.claude.com/docs/en/overview" target="_blank" rel="noopener">Docs</a></q>
    <q t="How Codex differs from ChatGPT">The same rule applies: the GPT models are shared, the environment differs. ChatGPT holds a conversation without project access; Codex works with code and runs commands.</q>
  </b-qa>
  <b-finding>
    <ex>The four types differ in two properties: where code runs and how model access works. Open-source and enterprise run on your computer and differ only in model access, which is where the cost difference comes from.</ex>
    <gen>Local types fit work with files and secrets on your computer, the cloud fits long and parallel tasks, chat fits tasks without project access. Constraints narrow the choice: an enterprise plan is not available in every jurisdiction<b-proof href="https://www.anthropic.com/supported-countries" quote="Anthropic: “To the extent permitted by law, Anthropic reserves the right to not provide its products or services to entities whose majority direct or indirect ownership is attributable to nations other than those listed in our Supported Regions Policy” — anthropic.com/supported-countries"/>.</gen>
    <do>Decide whether the task needs files on your computer, whether the agent should work without you, and which model you can use. The first points to a local type, the second to the cloud, neither to chat.</do>
  </b-finding>
