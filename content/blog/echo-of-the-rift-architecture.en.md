“Echo of the Rift” is an open 900 × 900 m island in the browser: no engine and no build step, one page and a set of modules. This is how it is put together: contexts, C4 diagrams down to the component level, and the five paths everything rests on.

<h2 id="contexts">Seven contexts</h2>

<table><thead><tr><th>Context</th><th>Responsible for</th><th>Main files</th><th>Owns</th></tr></thead><tbody><tr><td><b>🌍 World</b></td><td>terrain, snow, sky, vegetation, structures</td><td><code>terrain.js, atmosphere.js, vegetation.js, structures.js, worldfill.js</code></td><td>height, snow depth, trees, structures</td></tr><tr><td><b>🧍 Body and contact</b></td><td>the pilot’s pose, contact with rocks and other objects</td><td><code>interaction.js, rock-brain.js, pose-pipeline.js, body-spec.js, contact-core.js</code></td><td>bone pose, hand targets, body measurement</td></tr><tr><td><b>⚙️ Physics</b></td><td>where one can stand and what is solid</td><td><code>physics.js (Rapier), реестр Passport в странице</code></td><td>pilot position, colliders</td></tr><tr><td><b>📖 Story and interface</b></td><td>chapters, dialogue, combat, map and journal, saves</td><td><code>open-world.html: STAGES, Dialog, enemies</code></td><td>player progress (localStorage)</td></tr><tr><td><b>🎛 Quality</b></td><td>preset choice and frame smoothness</td><td><code>lowend.js, perf.js, texbudget.js, пресеты QUALITY</code></td><td>preset, render scale</td></tr><tr><td><b>📦 Assets</b></td><td>loading and storing models and textures</td><td><code>assets/pack, assets/veg, baked.js</code></td><td>models, textures, far-tree images</td></tr><tr><td><b>🤖 AI layer</b></td><td>live replies of the hermit (optional)</td><td><code>ai.js, ai-content.js, server/server.mjs</code></td><td>reply cache</td></tr></tbody></table>

Contexts talk through a shared <code>ctx</code> object and a few globals. Every fact has one owner: physics moves the pilot, the pose pipeline writes the bones, the registry knows the world’s objects.

<h2 id="rules">The rules everything rests on</h2>

<ul><li><strong>Physics is the only mover of the pilot.</strong> Everyone else gives a goal.</li><li><strong>The pose pipeline is the only writer of the bones.</strong> Others send requests.</li><li><strong>The Passport registry is the only one that knows the world’s objects.</strong> Collisions are built from it.</li><li><strong>A module fails alone.</strong> An error switches off only that module.</li><li><strong>A frame never waits for the network.</strong> The AI and the server never block rendering.</li><li><strong>One “inside the rock” measure.</strong> The game and the tests measure the same way.</li></ul>
