**สรุป:**

**ในตัวอย่างนี้:** ใน Kubernetes คนแก้ chart และ controller ปรับ node ให้ตรง ที่นี่คนแก้พจนานุกรม และเอเจนต์ปรับโค้ดให้ตรงแล้วตรวจด้วยเทสต์

**โดยทั่วไป:** ทั้งสองระบบแยกสถานะที่ต้องการออกจากสถานะจริง แล้ว reconcile กันเป็นวงจร คนในวงจรเปลี่ยนเฉพาะสถานะที่ต้องการ ทุกการแก้จึงกลายเป็นงานของผู้ลงมือทันที

**ขั้นต่อไป:** แก้ข้อกำหนดในพจนานุกรม แทนการแก้โค้ดด้วยมือ และสั่งให้เอเจนต์ปรับโค้ดให้ตรงกับพจนานุกรม

## การตรวจเห็นเฉพาะสิ่งที่ใส่ไว้ในมัน

ตัวอย่างคือการจองห้องประชุมจากข้อกำหนดแบ่งตาม aggregate: MUST สามข้อและ SHOULD หนึ่งข้อ

**Kubernetes:**

/healthz → 200

probe เขียว แต่บริการไม่ทำงาน

**Spec:**

MUST · ไม่ทับกันเทสต์

MUST · ไปข้างหน้าเท่านั้นเทสต์

MUST · 15 นาที → ปิดไม่มีการตรวจ

SHOULD · ช่องทางรีวิว

MUST ที่ครอบคลุม

**2 / 3:**

เทสต์เขียว แต่ MUST หนึ่งข้อไม่ถูกตรวจ

ทุก MUST → การตรวจของตัวเอง MUST ที่ไม่มีการตรวจ = ช่องโหว่ เขียว ≠ ถูกต้อง

probe มีแบบไหนและตรวจอะไร: Kubernetes: probe

**สรุป:**

**ในตัวอย่างนี้:** probe ตอบ "200" ขณะที่ออเดอร์ค้าง และเทสต์การจองเขียวขณะที่ไม่มีใครตรวจกฎ 15 นาที

**โดยทั่วไป:** การตรวจยืนยันเฉพาะสิ่งที่เขียนไว้ในมัน และไม่บอกอะไรเกี่ยวกับส่วนที่เหลือ จึงต้องนำการ์ด aggregate มาเทียบกับการตรวจ: MUST ที่ไม่มีการตรวจคือช่องโหว่ ไม่ใช่ข้อกำหนดที่เป็นจริงแล้ว

**ขั้นต่อไป:** ไล่ดู MUST ในพจนานุกรมของคุณและทำเครื่องหมายข้อที่ไม่มีเทสต์ แปลงแต่ละข้อเป็นงาน หรือลดระดับเป็น SHOULD อย่างตั้งใจ

## สภาพแวดล้อมเป็นตัวกำหนดว่าวงจรจะปิดหรือไม่

**คลัสเตอร์:** สภาพแวดล้อมของ controller

≈

**harness:** สภาพแวดล้อมของเอเจนต์

**รันโค้ด:** ถ้าไม่มี → เดาแทนข้อเท็จจริง

**เทสต์:** ถ้าไม่มี → ตรวจ MUST ไม่ได้

**ล็อก:** ถ้าไม่มี → มองไม่เห็นว่าอะไรพัง

**ข้อมูลทดสอบ:** ถ้าไม่มี → ตรวจบนตารางว่าง

**บริการผ่าน MCP:** ถ้าไม่มี → การเชื่อมต่อมองไม่เห็น

**Sandbox และสิทธิ์:** ถ้าไม่มี → เสี่ยงเกินกว่าจะให้ลงมือ

บทความแยก เลือกสภาพแวดล้อม: เปรียบเทียบ harness Claude Code, Codex, Cursor, Hermes และแชตบนแผนที่เดียว

**สรุป:**

**ในตัวอย่างนี้:** controller ของ Kubernetes ทำงานได้เพราะคลัสเตอร์ให้ API, node และ probe สำหรับวงจรเดียวกัน เอเจนต์ต้องรันโค้ด เทสต์ ล็อก ข้อมูล บริการ และ sandbox ได้

**โดยทั่วไป:** พจนานุกรมกำหนดสถานะที่ต้องการ แต่เฉพาะผู้ที่รันและวัดโค้ดได้เท่านั้นที่ reconcile โค้ดกับสถานะนั้นได้ สิ่งใดที่สภาพแวดล้อมไม่มี เอเจนต์ตรวจไม่ได้ และวงจรยังเปิดอยู่ตรงจุดนั้น

**ขั้นต่อไป:** ทำเครื่องหมายว่าเอเจนต์ของคุณมีความสามารถหกอย่างนี้ข้อไหนบ้าง สำหรับข้อที่ขาด ให้ตัดสินใจว่าจะเพิ่มลงใน harness หรือเปลี่ยน harness
