## საიდან ავიღოთ მონაცემები

ყველაფერი აგებულია ერთი ChatGPT Enterprise-ის ადმინისტრატორის კონსოლის ხუთი განყოფილებიდან. მიიტანეთ კურსორი i-ზე, რომ ზუსტად ნახოთ, რას შეიცავს თითოეული განყოფილება.

**როგორ გავაკეთოთ ექსპორტი.** კონსოლს მართლაც აქვს API-ები, მაგრამ ისინი მხოლოდ მონაცემების ნაწილს ფარავს: Codex-ის ანალიტიკას, კრედიტების ღირებულებას და მიმოწერის ჟურნალებს შესაბამისობის (compliance) მიზნით. მომხმარებლების, პროექტებისა და skills-ის ექსპორტები და პროდუქტების მიხედვით ლიდერბორდი ინტერფეისში უფრო ადვილად გროვდება. ექსპორტი Claude in Chrome-ისთვის კარგი სამუშაოა: ის ხსნის სწორ განყოფილებას, აყენებს ფილტრს, აჭერს ექსპორტს და ინახავს CSV-ს. ყოველი ნაბიჯი ეკრანზე ჩანს, ამიტომ არასწორი ფილტრი ან განყოფილება მაშინვე შეიმჩნევა, სანამ ციფრები ანგარიშამდე მივა.

**წვდომა.** კონსოლის API ყოველთვის ხელმისაწვდომი არ არის: კომპანიის უსაფრთხოების პოლიტიკა ხშირად ზღუდავს ადმინისტრატორის API გასაღებებს. ამ შემთხვევაში ყოველი განყოფილების ექსპორტი ინტერფეისიდან გააკეთეთ.
