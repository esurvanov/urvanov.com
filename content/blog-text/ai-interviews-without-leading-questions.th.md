## ข้อความ: การเขียนคำถาม

ในแชตหรือแบบสอบถามถามซ้ำได้ยาก คำถามที่เขียนไม่ดีจึงทำให้คำตอบเสียโดยแก้ไม่ได้ ห้าข้อผิดพลาดที่พบบ่อย:

นำคำตอบ

เครื่องมือนี้สะดวกสำหรับคุณแค่ไหน

เล่าถึงงานล่าสุดที่ใช้เวลาไปพอสมควร

ยั่วให้โต้แย้ง

ทำไมไม่ใช้เครื่องมือนี้ ในเมื่อบริษัทจ่ายเงินให้

งานแบบนี้ครั้งล่าสุดคุณทำอย่างไร พิจารณาทางเลือกอะไรบ้าง

ขอฟีเจอร์

คุณขาดฟีเจอร์อะไร

ในงานล่าสุด มีจุดไหนที่ต้องทำต่อเองด้วยมือ

สมมติ

ถ้ามีเอเจนต์ คุณจะใช้มากขึ้นไหม

ครั้งล่าสุดที่ผลลัพธ์ใช้ไม่ได้ คุณทำอย่างไร

ถามสองเรื่องพร้อมกัน

คุณทำอะไรกับเครื่องมือนี้ และบ่อยแค่ไหน

งานล่าสุดที่คุณทำด้วย AI คืออะไร

**สรุป:**

**ในตัวอย่างนี้:** คำถามที่แก้แล้วทั้งห้าข้อถามถึงเหตุการณ์ในอดีต

**โดยทั่วไป:** คำถามเรื่องความสะดวก ฟีเจอร์ และอนาคตได้ความเห็นมา การตัดสินใจซื้อต้องอิงสิ่งที่คนทำไปแล้ว คำถามที่ดีจึงถามถึงกรณีเฉพาะในอดีต

**ขั้นถัดไป:** อ่านคำถามในแชตและแบบสอบถามอีกรอบ แล้วเขียนคำถามที่มีคำว่า "สะดวก" "อยากได้ไหม" หรือ "ฟีเจอร์อะไร" ใหม่เป็นคำถามเกี่ยวกับงานล่าสุด

## กรอกตารางด้วย Claude Code

ส่งตารางทั้งหมดให้เอเจนต์ทำได้: Claude Code หรือเอเจนต์อื่นที่รองรับ MCP เชื่อมต่อ Airtable แล้วสร้างแถว ดึงข้อมูลรายงาน และวิเคราะห์บทสนทนาเอง

Claude Code หรือเอเจนต์อื่นที่รองรับ MCP Airtable MCPอ่านและเขียนตาราง Airtableทุกช่องและทุกสถานะ

**สร้างแถว:** จากรายชื่อคนที่เลือกไว้สัมภาษณ์: ชื่อ กลุ่ม สถานะ

**ดึงข้อมูลรายงาน:** โทเคน $ กิจกรรม ความถี่ตามรายงาน

**วิเคราะห์ช่องบันทึก:** ด้วย prompt เดียวกับใน ChatGPT: ช่องต่างๆ ความยาก ความถี่ที่บอกเอง คำพูดอ้างอิง

**อัปเดตสถานะ:** "ไม่ครบ" (คำตอบไม่สมบูรณ์) ถ้าผลวิเคราะห์มี "ไม่มีข้อมูล"

Airtable MCPวิธีเชื่อมต่อ

**สรุป:**

**ในตัวอย่างนี้:** เอเจนต์สร้างแถว ดึงรายงาน วิเคราะห์ช่องบันทึก และอัปเดตสถานะ: สี่ขั้นโดยไม่ต้องกรอกเอง

**โดยทั่วไป:** ผ่าน MCP เอเจนต์ทำงานกับตารางโดยตรง ผู้วิจัยเหลือหน้าที่คุยกับผู้ตอบและตรวจข้อสรุปกับคำพูดจริง prompt วิเคราะห์เดียวสำหรับทั้งเอเจนต์และ ChatGPT ทำให้แถวเทียบกันได้

**ขั้นถัดไป:** เชื่อม Airtable MCP กับ Claude Code และเริ่มด้วยคำสั่งเดียว: "สร้างแถวให้คนในรายชื่อด้วยสถานะ กำลังดำเนินการ"

## แบบสอบถาม

แบบสอบถามเขียนหลังการสัมภาษณ์ เมื่อรู้แล้วว่ามีงานและความยากแบบไหนบ้าง ส่งถึงทั้งบริษัทเพื่อดูว่าเรื่องเหล่านั้นแพร่หลายแค่ไหน คำถามสั้น และตัวเลือกคำตอบมาจากการวิเคราะห์บทสัมภาษณ์

1

คุณทำงานต่อไปนี้ข้อใดบ้างในที่ทำงาน เลือก: งานจากบทสัมภาษณ์ · อื่นๆ ช่องกรอกเอง งาน

2

คุณทำงานเหล่านี้บ่อยแค่ไหน เลือก: ทุกวัน · ทุกสัปดาห์ · น้อยกว่านั้น · ไม่ได้ทำ ความถี่ของงาน

3

คุณใช้เครื่องมือใดกับงานเหล่านี้ เลือก: ChatGPT · Claude · Cursor · เครื่องมือ AI อื่น · ไม่ใช้ AI เครื่องมือ

4

คุณเจอความยากอะไรบ้างในงานเหล่านี้ เลือก: ความยากจากบทสัมภาษณ์ · ไม่เจอความยากใดเลย · อื่นๆ ช่องกรอกเอง ความยาก

5

ความยากนี้ขัดขวางงานบ่อยแค่ไหน เลือก: เกือบทุกงาน · บางครั้ง · นานๆ ครั้ง ความถี่ของความยาก

6

ส่งผลต่อผลลัพธ์มากแค่ไหน เลือก: ขัดขวางมาก · ขัดขวาง · แทบไม่มีผล ผลกระทบ

7

ตอนนี้คุณแก้ปัญหาความยากนี้อย่างไร ช่องกรอกเอง · ไม่ได้ทำอะไร วิธีแก้ขัด

8

มีอะไรสำคัญอีกที่คำถามไม่ได้ถาม ช่องกรอกเอง ที่ตกหล่น

**สรุป:**

**ในตัวอย่างนี้:** แปดคำถามสั้น: หกข้อแบบเลือกคำตอบ โดยตัวเลือกมาจากบทสัมภาษณ์ และสองข้อเป็นช่องกรอกเอง

**โดยทั่วไป:** การสัมภาษณ์บอกว่ามีงานและความยากอะไรบ้าง แบบสอบถามบอกว่ามีคนเจอกี่คนและขัดขวางมากแค่ไหน ตัวเลือก "ไม่เจอความยากใดเลย" "ไม่ใช้ AI" และช่องกรอกเองจับสิ่งที่การสัมภาษณ์พลาดไป

**ขั้นถัดไป:** รวบรวมตัวเลือกคำตอบจากการวิเคราะห์บทสัมภาษณ์ แล้วส่งแบบสอบถามถึงทั้งบริษัท นับสัดส่วนคนที่เจอความยากแต่ละอย่าง บ่อยแค่ไหน และขัดขวางมากเท่าไร สัดส่วนเหล่านี้ป้อนเข้าขั้นตอนการตัดสินใจในรายงาน

**โดยทั่วไป:** การวิเคราะห์เก็บงานทั้งชิ้น ไม่ใช่แค่ความยาก: ถ้าไม่มีบริบท วิธีที่เลือก และแรงที่ใช้ จะบอกไม่ได้ว่าต้องมีเครื่องมือใหม่หรือไม่ สิ่งที่ซ้ำในบทสัมภาษณ์บอกว่าควรตรวจอะไร ไม่ได้บอกว่ามีคนเจอกี่คน เรื่องนั้นมีแต่แบบสอบถามที่บอกได้ prompt เดียวสำหรับทุกบทสนทนาทำให้ช่องเทียบกันได้ และคำว่า "ไม่มีข้อมูล" กัน ChatGPT ไม่ให้แต่งเรื่องเอง

**ขั้นถัดไป:** เมื่อมีผลวิเคราะห์สะสมหลายชิ้น ให้จัดกลุ่มตารางตามความยาก แล้วย้ายสิ่งที่ซ้ำไปเป็นตัวเลือกคำตอบของแบบสอบถาม บันทึก "ไม่มีความยาก" เป็นผลลัพธ์หนึ่ง ใช้หมวดหมู่จากตารางสัญญาณของรายงาน และเพิ่มหมวดใหม่ถ้าไม่มีหมวดใดตรง การตัดสินใจเรื่องโครงการนำร่องเป็นไปตามขั้นตอนในรายงาน
